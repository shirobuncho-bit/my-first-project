# my-first-project

## てるしのくんRUN

真夜中から日の出まで、坂やループを駆け抜けて「日の出の祭壇」をめざすハイスピード横スクロールアクションです。HTML5 Canvas だけで動き、`game/index.html` 1 ファイルで完結しています。

- **遊ぶ**: GitHub Pages を有効にすると https://shirobuncho-bit.github.io/my-first-project/game/ で遊べます（ローカルでは `game/index.html` をブラウザで開くだけ）
- **操作**: ←→ 移動 / Space・Z ジャンプ / Shift・X 長押しでためて、はなすとスーパーダッシュ / P ポーズ / M 音のオン・オフ
- **スマホ**: 画面のボタンで操作できます（縦持ちでも横持ちでも OK）
- **評価**: クリアタイムとスコアそれぞれに S〜D のランク、2 つを合わせた総合ランク

### 裏のテーマ：こころの夜と夜明け

このゲームには、メンタルヘルスをそっと重ねています。

- **夜**：気持ちが重く沈んだ時間。てるしのくんは困り顔のまま走りだし、夜明けが近づくと表情が少しずつゆるみ、日の出で笑顔になります
- **どんよりぐも**：頭の中のネガティブな声（「どうせ むりだよ」など）。晴らすと小さな光にかわります
- **ひかりのしずく**：日々の小さなよろこび（あったかいお茶、ぐっすり眠れた、など）
- **ランタン（中間地点）**：だれかの支え。「休んでもいいんだよ」「だれかに話すと、すこし軽くなる」
- **一時停止**：「休むのも、前に進むこと。」
- **ミス・ゲームオーバー**：責めずに「きょうは、ここまで。ゆっくり休んで、また明日。」

つらい気持ちが続くときは、ひとりで抱えこまず、だれかに話してみてください。相談先は厚生労働省の「まもろうよ こころ」で調べられます。
